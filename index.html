DongJun Kim

Security Researcher · Agentic Security & Cyber Benchmarks

I'm an M.S. student in Computer Science at UIUC, building AI agents that find real vulnerabilities and benchmarks that measure the cyber capabilities of frontier models. My work spans agentic vulnerability discovery in production Windows binaries (DeepBinary) and long-horizon security evaluation (SEC-bench Pro, CyberDual), now used by OpenAI, Google, DeepSeek, and NIST to evaluate frontier models. This builds on a background in Windows kernel vulnerability research and exploitation, as a security researcher at Enki WhiteHat (2024 — 2026). I've been recognized as a Microsoft MSRC Most Valuable Researcher (2025 and 2026, Global Top 100), with 90 CVEs disclosed.

Papers

arXiv 2026

CyberDual: AI Attackers versus AI Code Reviewers in Real Software Maintenance

Chenyuan Yang*, Hwiwon Lee*, Jongseong Kim, Yihan Yang, DongJun Kim, Yinfang Chen, Lingming Zhang (* equal contribution)

Evaluates AI agents as both attackers and code reviewers in real software maintenance: attackers embed exploitable vulnerabilities in open-source code changes, reviewers try to detect and repair them, and re-executing the attacker's proof of concept decides whether the exploit survives. Includes 1,088 valid attacks from six attackers against three agentic reviewers.

arXiv GitHub Leaderboard

Benchmark 2026

DeepBinary: Can AI Agents Uncover Deep Vulnerabilities in Production Binaries?

Jongseong Kim*, Hwiwon Lee*, DongJun Kim, Lingming Zhang (* equal contribution)

A leaderboard benchmarking AI agents on real Windows system binaries, scoring findings by executable evidence, security impact, and estimated bounty. All zero-days found through this research have been reported to MSRC.

Leaderboard GitHub

arXiv 2026

SEC-bench Pro: Can Language Models Solve Long-Horizon Software Security Tasks?

Hwiwon Lee, Jiawei Liu, DongJun Kim, Ziqi Zhang, Chunqiu Steven Xia, Lingming Zhang

A benchmark that challenges modern coding agents with long-horizon security tasks in critical, high-complexity software systems (at million-line scale), including vulnerabilities with over $1 million in cumulative bug bounties. Adopted for frontier-model evaluation by OpenAI (GPT-5.5-Cyber, GPT-6 Astra), Google (Gemini 4 Carbon), DeepSeek, and NIST CAISI.
