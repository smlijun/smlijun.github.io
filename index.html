Agentic security and cyber benchmarks for frontier models.

I build AI agents that find real vulnerabilities and benchmarks that measure the cyber capabilities of frontier models — from agentic vulnerability discovery in production Windows binaries (DeepBinary) to long-horizon security evaluation (SEC-bench Pro, CyberDual), now used by OpenAI, Google, DeepSeek, and NIST. This work grows out of Windows kernel vulnerability research at Enki WhiteHat (2024 — 2026).

Research

Preprint · arXiv 2026

CyberDual: AI Attackers versus AI Code Reviewers in Real Software Maintenance

Chenyuan Yang*, Hwiwon Lee*, Jongseong Kim, Yihan Yang, DongJun Kim, Yinfang Chen, Lingming Zhang

Agents act as attackers that embed exploitable vulnerabilities in open-source code changes and as reviewers that try to catch and repair them; re-running the attacker's proof of concept decides whether the exploit survives. 1,088 valid attacks from six attackers against three agentic reviewers.

Benchmark · 2026

DeepBinary: Can AI Agents Uncover Deep Vulnerabilities in Production Binaries?

Jongseong Kim*, Hwiwon Lee*, DongJun Kim, Lingming Zhang

Benchmarks AI agents on real Windows system binaries, scoring findings by executable evidence, security impact, and estimated bounty. Every zero-day found through this work has been reported to MSRC.

Preprint · arXiv 2026

SEC-bench Pro: Can Language Models Solve Long-Horizon Software Security Tasks?

Hwiwon Lee, Jiawei Liu, DongJun Kim, Ziqi Zhang, Chunqiu Steven Xia, Lingming Zhang

Long-horizon security tasks in million-line systems — V8, SpiderMonkey, and the Linux kernel — including vulnerabilities with over $1 million in cumulative bounties. Adopted for frontier-model evaluation by OpenAI (GPT-5.5-Cyber, GPT-6 Astra), Google (Gemini 4 Carbon), DeepSeek, and NIST CAISI.
