DongJun Kim

Security Researcher · Windows Kernel & Browser

I'm a security researcher at Enki WhiteHat specializing in Windows kernel vulnerability research and exploitation. I focus on discovering privilege-escalation bugs in kernel drivers, system services, and COM/RPC internals through static analysis and fuzzing, with additional research on Chromium browser security. I've been recognized as a Microsoft MSRC Most Valuable Researcher (2025, Global Top 100), with 30+ CVEs disclosed. Starting Fall 2026, I'll be pursuing my M.S. in Computer Science at UIUC.
